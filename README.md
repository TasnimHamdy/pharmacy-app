# Pharmacy Management System 💊

A desktop-based pharmacy management application designed to help manage drug inventory efficiently, with integrated machine learning for automatic drug classification.

## 📌 Features

- Add, update, and manage medications
- Track drug quantity, production date, and expiration date
- Search and filter drugs by name or category
- Automatic drug classification using a machine learning model
- Manual category editing for better accuracy
- Export pharmacy data to Excel reports
- User-friendly interface for real-world pharmacy operations

## 🧠 Machine Learning Integration

- Utilizes a trained classification model to automatically categorize medications
- Supports manual overrides to ensure flexibility and correctness

## 🛠️ Tech Stack

- Python
- Tkinter (GUI)
- Scikit-learn
- Pandas
- NumPy
- Excel Export
